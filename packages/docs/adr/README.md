# Architecture Decision Records (ADRs)

This directory contains records of significant architectural and design decisions made for the **Openedup / Charan Interiors** platform.

## What is an ADR?

An Architecture Decision Record (ADR) captures a single architectural decision along with its context, considered alternatives, and consequences (both positive and negative).
