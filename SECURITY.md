# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of this project very seriously. If you believe you have discovered a vulnerability, please do NOT create a public issue.

Instead, please report security vulnerabilities via:

1. GitHub Private Vulnerability Reporting (recommended) on the repository page under `Security` > `Advisories` > `Report a vulnerability`.
2. Or contact the maintainers directly via email.

Please provide:

- A description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept to reproduce the issue.
- Any suggested mitigations.

We will acknowledge receipt of your report within 48 hours and work with you to triage and resolve the issue before public disclosure.
